# Expand your team with Copilot

<img src="https://octodex.github.com/images/Professortocat_v2.png" align="right" height="200px" alt="Professortocat" />

Welcome! In this self-paced exercise, learn how to delegate work to GitHub Copilot, collaborate on its pull requests, customize its repository instructions and environment, and manage multiple tasks with the Agents tab and panel.

## Start the exercise

[![Go to the exercise](https://img.shields.io/badge/Go%20to%20Exercise-%E2%86%92-1f883d?style=for-the-badge&logo=github&labelColor=197935)](https://github.com/akazi-rk/skills-expand-your-team-with-copilot/issues/1)

Follow the guided activities in order:

1. [Enable Copilot and assign an issue](.github/steps/1-assign.md)
2. [Collaborate with Copilot](.github/steps/2-collaborate.md)
3. [Prepare Copilot's environment](.github/steps/3-prepare-environment.md)
4. [Manage multiple tasks](.github/steps/4-play-time.md)

The optional activity to run the sample website is not required to complete the exercise. If you'd like to set it up locally, see the [development guide](docs/how-to-develop.md).

Take breaks whenever you like, and enjoy learning at your own pace! 💚
